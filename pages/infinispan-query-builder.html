Querying Infinispan with Hibernate Search and Lucene

In this second part of our Infinispan integration series, we'll explore how to effectively query data from Infinispan using Hibernate Search and Lucene. We'll cover everything from setting up the search manager to executing complex queries with pagination.

1. Setting Up the Search Manager

The first step in querying Infinispan is to create a SearchManager instance. This manager will be your primary interface for building and executing queries:

// Initialize the search manager
SearchManager searchManager = Search.getSearchManager(cache);
searchManager.getStatistics().setStatisticsEnabled(true);
Tip: Enabling statistics can help monitor query performance and optimize your application, but may have a small performance impact in production.

2. Building Queries with Hibernate Search

Hibernate Search provides a fluent API for building Lucene queries. Here's how to create a QueryBuilder for your entity class:

// Create a query builder for your class
QueryBuilder builder = searchManager.buildQueryBuilderForClass(YourClass.class).get();

2.1 Building Boolean Queries

For complex queries involving multiple conditions, use BooleanJunction:

// Create a boolean query builder
BooleanJunction<BooleanJunction> andQueryBuilder = builder.bool();

// Add conditions using should() for OR operations
andQueryBuilder.should(builder.keyword()
    .onField("fieldName")
    .matching(searchValue)
    .createQuery());

2.2 Creating the Final Query

You can either create a specific query with conditions or query all records:

// Create query with conditions
Query query = andQueryBuilder.createQuery();

// OR query all records
Query query = builder.all().createQuery();

3. Executing Complex Queries

Once you have built your query, you can execute it using the CacheQuery interface:

// Create a cache query with type safety
CacheQuery<ResultType> cacheQuery = searchManager.getQuery(query, IndexedQueryMode.FETCH, ResultType.class);
Note: The IndexedQueryMode.FETCH parameter tells Infinispan to fetch the complete objects. Use SKIP_LOADING if you only need the indexed fields.

4. Pagination and Sorting

For large result sets, you'll want to implement pagination and sorting:

// Create sort fields
Sort sort = new Sort(new SortField("fieldName", SortField.Type.STRING));

// Apply sorting and pagination
CacheQuery<ResultType> sortedQuery = cacheQuery
    .sort(sort)
    .firstResult(page * pageSize)
    .maxResults(pageSize);

// Execute the query and get results
List<ResultType> results = sortedQuery.list();

5. Best Practices

  • Query Optimization
    • Use appropriate field indexing strategies
    • Leverage keyword queries for exact matches
    • Use fuzzy queries for approximate matches
  • Performance Considerations
    • Always use pagination for large result sets
    • Monitor query execution times using statistics
    • Consider index optimization for frequently queried fields
  • Error Handling
    • Implement proper exception handling for search operations
    • Handle null results and empty result sets gracefully
    • Consider implementing retry mechanisms for temporary failures

Complete Example

Here's a complete example putting all the pieces together:

public List<ResultType> searchWithPagination(String searchTerm, int page, int size) {
    SearchManager searchManager = Search.getSearchManager(cache);

    // Create query builder
    QueryBuilder builder = searchManager.buildQueryBuilderForClass(ResultType.class).get();

    // Build the query
    BooleanJunction<BooleanJunction> junction = builder.bool();
    junction.should(builder.keyword()
        .onField("searchableField")
        .matching(searchTerm)
        .createQuery());

    Query query = junction.createQuery();

    // Execute with pagination
    CacheQuery<ResultType> cacheQuery = searchManager.getQuery(query, IndexedQueryMode.FETCH, ResultType.class);
    CacheQuery<ResultType> sortedQuery = cacheQuery
        .sort(new Sort(new SortField("sortField", SortField.Type.STRING)))
        .firstResult(page * size)
        .maxResults(size);

    return sortedQuery.list();
}
